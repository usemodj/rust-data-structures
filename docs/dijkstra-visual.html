다익스트라 알고리즘 실행 시각화

아래는 주어진 그래프에서 다익스트라 알고리즘이 단계별로 실행되는 과정을 보여줍니다:

📊 정점 0에서 시작하여 각 단계별로 최단 경로를 확정하고, 거리를 갱신하는 과정

그래프 구조

다음은 Rust 예제에서 사용하는 그래프입니다:

graph = vec![vec![(1, 4), (2, 1)], vec![(3, 1)], vec![(1, 2), (3, 5)], vec![]];

📊 오렌지색 화살표는 정점 0에서 시작하는 최단 경로를 나타냅니다

그래프 설명:

  • 정점 0 → 정점 1 (비용 4)
  • 정점 0 → 정점 2 (비용 1)
  • 정점 2 → 정점 1 (비용 2)
  • 정점 2 → 정점 3 (비용 5)
  • 정점 1 → 정점 3 (비용 1)

단계 확정 정점 거리 처리 내용 갱신된 거리

✓ 단계 1 - 정점 0 확정 (시작)
거리 배열: [0, ∞, ∞, ∞] → [0, 4, 1, ∞]
우선순위 큐: (1, 2), (4, 1) 추가
✓ 단계 2 - 정점 2 확정 (최소 거리)
정점 2에서 나가는 간선 처리:
• 2→1: 거리 1+2 = 3 (기존 4보다 개선!) ✓
• 2→3: 거리 1+5 = 6
거리 배열: [0, 4, 1, ∞] → [0, 3, 1, 6]
✓ 단계 3 - 정점 1 확정
정점 1에서 나가는 간선 처리:
• 1→3: 거리 3+1 = 4 (기존 6보다 개선!) ✓
거리 배열: [0, 3, 1, 6] → [0, 3, 1, 4]
✓ 단계 4 - 정점 3 확정
정점 3에서 나가는 간선 없음
모든 정점이 확정되었으므로 종료
